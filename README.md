# Portfolio

Situs portofolio statis: React, TypeScript, Vite, dan Tailwind CSS. Dua bahasa (EN/ID).

## Menjalankan
```
npm install
npm run dev
```

## Yang perlu diganti
Di bagian atas `src/App.tsx`: `PROFILE` (nama, WhatsApp, email, GitHub), teks di `COPY`, dan `STATS`.

## Proyek otomatis
Repo publik di akun GitHub yang berisi topik `portfolio` tampil otomatis di hero dan bagian Karya.
Isi kolom Website, Description, dan topik teknologi pada repo itu. Hasil disimpan 1 jam di browser pengunjung.

## Deploy gratis
Hubungkan repo ke Vercel. Pengaturan bawaan Vite sudah cukup.
